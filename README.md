# Skillonomicon

A set of eldritch agentic skills, consolidated into their own "Necronomicon".

## Installing Skills

The recommended way is through [apm](https://microsoft.github.io/apm/). 

Once you have it installed and initialized on your project run:

```bash
apm install rodolphocastro/skillonomicon --skill <skill-name>
```

> For an even safer approach remember to pin the tag which you want to use!

You may also:

- Use `npx skills`
- Manually copy the skill's folder from this repository over to your agent's skills folder
