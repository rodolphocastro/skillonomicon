# Skillonomicon

A set of eldritch agentic skills, consolidated into their own "Necronomicon".

## Installing Skills

The quickest and safest way is through [apm](https://microsoft.github.io/apm/), by running:

```bash
apm install rodolphocastro/skillonomicon --skill <desired skill>
```

> For an even safer approach remember to pin the tag which you want to use!
